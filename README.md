# Minecrafter — український Minecraft-портал

Атмосферний багатосторінковий редизайн за наданим технічним завданням: 25 сторінок + 404, 12 оригінальних voxel-ілюстрацій, Java/Bedrock-інструкції, копіювання IP, пошук команд, адаптивна навігація, FAQ та живий статус із коректними станами помилки.

## Структура

- `content/site.json` — IP, порти, зовнішні посилання, статус API, режими, команда, новини й події.
- `content/guide.json` — FAQ, команди та короткий огляд правил.
- `scripts/build.py` — генерація семантичного HTML, метаданих, sitemap та 404.
- `scripts/verify.py` — перевірка маршрутів, локальних ресурсів і метаданих.
- `dist/` — повністю готовий статичний сайт; CSS, JS та оптимізовані WebP у `dist/assets/`.
- `.github/workflows/pages.yml` — автоматична публікація через GitHub Pages.

## Локальний запуск

Потрібні Python 3.12+ і Node.js для синтаксичної перевірки JavaScript. Зовнішні Python-пакети не потрібні.

```sh
python scripts/build.py
python scripts/verify.py
node --check dist/assets/site.js
python -m http.server 8000 --directory dist
```

Відкрий `http://localhost:8000`. Головний контент та навігація працюють без JavaScript. Скрипт додає копіювання, діалог меню, пошук, вкладки та ефекти.

## Редагування

Зміни JSON у `content/`, запусти `python scripts/build.py` і збережи також оновлений HTML у `dist/`. Дизайн і поведінка редагуються безпосередньо в `dist/assets/site.css` та `dist/assets/site.js`. Зображення мають повнорозмірну та 640-піксельну WebP-версії.

Щоб вимкнути зовнішню перевірку онлайну, встанови `status.enabled: false`. Якщо сервіс недоступний або повертає застарілу відповідь, сайт показує невідомий статус. Числа онлайну не вигадуються.

Новини й події спочатку ведуть до офіційного Discord. Власні підтверджені записи можна додати в `news` або `events`: `title`, `description`, `date` (ISO), `url`.

## GitHub Pages

У Settings → Pages джерелом має бути GitHub Actions. Після push у `main` workflow рендерить сайт з адресою Pages, перевіряє локальні посилання та публікує `dist/`. Жодного персонального токена у workflow немає — використовуються стандартні дозволи GitHub Actions.

Для іншого хостингу розмісти вміст `dist/` у публічному каталозі. За потреби перед генерацією задай `SITE_ORIGIN`, щоб canonical, Open Graph і sitemap відповідали фактичній адресі.
